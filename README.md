# Whitby Invitational

A live dashboard for an annual golf tournament: standings, scores, and event info in one clean, mobile-friendly page.

## What it does
- Tournament standings and scoring at a glance
- Event details for players and guests
- Fast, single-page experience that works on a phone on the course

## Tech
- Single-file static HTML, CSS, and JavaScript
- Deployed on Vercel

## Run locally
Open `index.html` in a browser. No build step.
